# 阵列重构后端服务

地基监视雷达均匀线阵的方向图计算与副瓣重构后端。接替原先博士后手工改脚本
的流程：阵列定义、健康事件溯源、任意时刻状态/方向图查询、副瓣模板驱动的
加权重构（后台作业）、方案版本管理、回放审计、重启恢复。

## 运行

```bash
docker compose up --build        # api: http://localhost:8000, redis: 6379 (AOF 持久化)
```

本地开发：

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest                           # 35 个测试（fakeredis，无需真实 Redis）
REDIS_URL=redis://localhost:6379/0 uvicorn 'app.main:create_app' --factory
```

## 模块划分

| 模块 | 职责 |
|---|---|
| `app/pattern.py` | 阵列模型：导向矩阵、阵因子、归一化方向图、指标（主瓣指向/半功率宽度/第一零点/最高副瓣） |
| `app/events.py` | 健康事件与状态推导（事件溯源，纯函数折叠） |
| `app/reconfigure.py` | 加权重构求解器（自研 FISTA，不用现成优化库） |
| `app/jobs.py` | 作业调度：后台线程、进度、取消、作废 |
| `app/storage.py` | Redis 持久化层 |
| `app/service.py` | 应用服务：把以上模块串成业务流 |
| `app/schemas.py` / `app/main.py` | 接口入参校验与 FastAPI 路由 |

## 阵列模型约定

- 单元位于 `x_n = n·d`（n = 0..N-1），d 以波长为单位；角度为偏离法线的度数。
- 阵因子 `AF(θ) = Σ w_n·exp(j2πx_n·sinθ)`；实际方向图用 `w_n·h_n`，其中
  `h_n` 是由健康事件推出的复健康因子（失效单元为 0，幅度/相位误差折算成复增益）。
- 参考值已验证：8 单元、半波长、等幅同相 → 第一零点 ±14.48°、最高副瓣
  −12.80 dB、半功率宽度 12.80°；指向 30° 时主瓣在 30°；4 号单元失效后
  最高副瓣 −8.17 dB（≈ −8.2 dB）。

## 健康事件与回放一致性

每条事件带事件编号、时刻、单元号（1 基）、变化（failed / amplitude_error /
phase_error / recovered）。存储层按事件编号去重（重复提交返回
`applied=false`，只生效一次）；任意时刻 t 的状态由所有 `时刻 ≤ t` 的事件按
`(时刻, 到达序号)` 排序折叠得到——晚到的事件因此自动归位。

一致性靠两点保证：

1. 在线处理与 `/replay` 共用同一个折叠函数，没有第二份状态推导逻辑；
2. 每个方案版本记录 `valid_from`（其依据事件集合的最大时刻）与
   `basis_event_ids`；t 时刻的生效版本 = `valid_from ≤ t` 中
   `(valid_from, 序号)` 最大者，在线"当前生效"等价于 t=+∞ 时的同一规则。

## 重构求解器（设计理由）

**表述。** 由于全体加权同乘非零复数不改变归一化方向图，可不失一般性地固定
指向处阵因子的相位：`Im AF(θ0)=0`、`s = Re AF(θ0)`。于是副瓣模板约束
`|AF(θ)| ≤ m(θ)·s`、失效单元 `w_n=0`、幅度上限 `|w_n|≤cap`、主瓣增益
`s ≥ g_min` 全是关于 w 的凸约束——"满足模板的加权"是**凸可行性问题**，
没有局部极小陷阱。这是不用遗传算法/粒子群等启发式方法的理由。

**方法。** 不调用现成优化库，自研 FISTA（带回溯线搜索与函数值自适应重启的
加速投影梯度法），最小化凸罚函数

```
P(w) = mean_θ max(|AF(θ)| − m(θ)·s, 0)² + 50·max(g_min − s, 0)² + 50·Im(AF(θ0))²
```

梯度有解析式（Wirtinger），每次迭代投影回约束集（失效位清零、幅度截断）。
模板可满足 ⟺ min P = 0；因此罚值是否归零就是可行性判据。解析梯度已用
有限差分校验。

**终止（绝不无限迭代）。** 三者先到为准：
1. 收敛：最大模板违反量与主瓣增益亏量均 ≤ `tolerance_db`（默认 0.02 dB）；
2. 停滞：连续 300 次评估最优评分无改善（判定不可满足的依据）；
3. 达到 `max_iterations` 上限。

无论以何种方式停止，都如实返回迄今最优加权、违反最严重的角度与超出量
（`worst_angle_deg` / `worst_excess_db`），作业状态记为 `infeasible`；
最优加权仍存档为版本但不生效（生效位只给满足模板的方案）。

**算例。** 8 单元等幅阵列 4 号单元失效后最高副瓣 −8.17 dB。物理上该阵列的
副瓣可行性边界约 −12 dB（且需付出约 5 dB 主瓣损失），−15 dB 不可达——
求解器对此如实报不可满足。测试用可达模板：±18° 以外 ≤ −10 dB、允许主瓣
损失 3 dB，求解器约 640 次迭代收敛（< 0.1 s），失效位加权严格为 0。

## 起点选择：warm 还是 cold

自动重构默认 **warm（从当前生效方案出发）**，手动作业可选 `cold`（等幅 +
线性相位梯度）。因为问题是凸的，两种起点收敛到同一全局最优（测试已验证
两者满足同一模板且解一致）；区别在于：

- warm：迭代更少（起点已在可行域附近），且新方案相对旧方案变动幅度小，
  TR 组件功率/相位 slew 小，切换瞬态小——维修窗口期在线运行的合理默认；
- cold：与历史无关的规范化解，便于复现与对比，作为基准保留。

## 作业生命周期

`queued → running → succeeded | infeasible | cancelled | superseded | failed`，
另有 `stale`（完成时依据的状态已过期，结果丢弃）与 `aborted`（重启时仍未完成）。

- 同一时刻至多一个作业运行；提交新作业会作废运行中的旧作业；
- 新健康事件到达：未完成作业作废；若当前生效方案在新状态下违反其模板
  （违反量 > 0.05 dB），自动以最新状态重新发起重构（warm 起点）；
  若仍满足模板则不浪费算力（这是"重新发起"的触发条件）；
- 作业依据的事件集合（`basis`）在启动时快照，完成时若状态已变则结果作废，
  新事件处理流程已发起替代作业，保证版本链不含过期方案；
- 取消是协作式的，求解器每次迭代检查一次标志位。

## 持久化与重启

事件、版本、作业、阵列定义、生效版本指针全部存 Redis（compose 中
`redis:7-alpine` 开 AOF everysec）。重启后：阵列、事件、版本、生效方案原样
恢复；未完成作业标记 `aborted`；若生效方案在当前状态下违反模板则补发自动
重构。测试用 fakeredis 覆盖恢复路径。

## 接口

| 方法/路径 | 说明 |
|---|---|
| `PUT /array` | 定义阵列（单元数、间距、各单元幅度/相位、指向）；重定义会清空历史 |
| `GET /array` | 当前阵列定义 |
| `POST /events` | 提交健康事件；返回 `applied` 与可能触发的 `auto_job` |
| `GET /events` | 全部事件（到达序） |
| `GET /state?t=` | t 时刻阵列状态（缺省为最新）：各单元误差、健康因子、失效列表 |
| `GET /pattern?t=&version_id=&include_pattern=&step_deg=` | 实际方向图指标，可选采样点 |
| `GET /array-factor?theta=...&t=&version_id=` | 任意方向复阵因子 |
| `GET /replay?t=` | t 时刻状态 + 生效方案 + 指标（回放） |
| `POST /jobs` | 提交重构作业（模板、指向、主瓣损失预算、幅度上限、起点、迭代上限） |
| `GET /jobs` / `GET /jobs/{id}` | 作业列表 / 状态、进度、结果 |
| `POST /jobs/{id}/cancel` | 取消作业 |
| `GET /versions` / `GET /versions/{id}` | 方案版本（绑定事件集合与模板） |
| `GET /versions/compare?a=&b=` | 方案对比：副瓣、主瓣损失、各单元加权变化 |
| `GET /health` | 存活检查 |

**拒收规则**（422 或 400）：单元数 < 2；间距非正或非有限；加权幅度为负或
非有限；加权数量与单元数不符；事件引用不存在的单元；幅度/相位事件缺数值；
模板区间越出 ±90°、下限 ≥ 上限或相互重叠；允许的主瓣损失为负；迭代上限 < 1。

## 不变量（均有测试）

- 全体加权同乘非零复数，归一化方向图不变；
- 加权序列整体反转，方向图关于法线镜像；
- 等幅阵列加线性相位梯度，主瓣移到对应方向；
- 失效单元的加权在任何方案里严格为零（投影保证，测试断言 `== 0`）。
